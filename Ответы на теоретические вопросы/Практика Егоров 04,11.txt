1.Отличие коллайдера от коллизии
Коллайдер — это компонент объекта, задающий его физическую форму и границы для работы физического движка.
Коллизия — это событие физического взаимодействия, которое возникает при соприкосновении или пересечении двух коллайдеров.
2. Отличие while от do while
while — вначале проверяет условие и только при его истинности выполняет тело цикла. Если условие ложно сразу, цикл пропускается.
do while — сначала выполняет команды внутри цикла, а затем проверяет условие. Поэтому тело такого цикла запускается минимум один раз.
3. Методы Web-запросов (HTTP-методы)
GET — используется для получения информации с сервера, например данных профиля или содержимого страницы.
POST — передает данные на сервер, обычно для создания новой записи, например при регистрации пользователя.
PUT — заменяет ресурс на сервере целиком переданными данными.
PATCH — изменяет только отдельные поля ресурса, не перезаписывая остальные данные.
DELETE — отправляет запрос на удаление выбранного ресурса.
4. Когда используется OnCollision и OnTrigger
OnCollision используется, когда объекты физически сталкиваются и отскакивают друг от друга. Для этого у объектов должны быть твердые коллайдеры и хотя бы один компонент Rigidbody.
OnTrigger используется для зон обнаружения, когда объекты должны проходить друг сквозь друга без физического столкновения.
5. Для чего нужен интерфейс / класс Input
Input позволяет получать действия пользователя — нажатия клавиш, клики мыши, команды геймпада или касания экрана — и использовать их в игровой логике.
